# T-003 · Source registry + ingestion adapters #1–7,13 (Phase 0 Foundation)

**Epic:** Phase 0 — Foundation · **Owner:** coder → sr-dev review · **Status:** To Do

## Goal
Implement read-only ingestion for the first batch of sources (§4.1): wires (#1), FOMC/statistical (#2,#3,#5,#6,#7), and market data (#13). Each adapter writes `EventObject`-shaped rows into T-001's schema with source-tier metadata baked in.

## Source scope (this card)
| # | Source | Type | Cadence | Tier (§4.2) |
|---|--------|------|---------|-------------|
| 1 | Major wires (Reuters/AP/Bloomberg-tier, Benzinga, DJ) | News | Continuous | T2 |
| 2 | FOMC statements/minutes/dot plots/speakers | Official | ~8wks + continuous | T1 |
| 3 | Economic calendar: NFP, CPI, PCE, ISM, retail sales, claims | Structured | Scheduled | T1 |
| 5 | FRED / Treasury: 10Y, 2Y, 10Y TIPS real yields, breakevens | Structured | Daily | T1 |
| 6 | EIA weekly petroleum status (crude inventories, SPR) | Official | Weekly | T1 |
| 7 | Treasury TIC + Japan MoF weekly flows | Official | Weekly/monthly | T1 |
| 13 | Futures/reference prices: GC, CL, lumber/timber, TNX, DX, VIX | Market | Delayed OK | T2 |

## Deliverables
1. `ingestion/registry.py` — loads `source_registry` rows from T-001; tier weights applied at write time (T1 1.00, T2 0.80).
2. One adapter per source in `ingestion/adapters/`, each returning a normalized list of EventObjects with: source_id, published_at (UTC publisher-stated), retrieved_at, url, raw_text, language, source_tier, event_type enum, entities, direction_assertions, numbers_extracted, novelty_score, extractor_confidence.
3. Structured feeds (#3,#5,#6,#7,#13) parse numeric fields from the structured feed directly — LLM handles narrative only (§5.2). No arithmetic in free-form text.
4. A `--sources 1,2,3,5,6,7,13` CLI entrypoint that runs all adapters once and writes rows (idempotent by published_at + url).

## Acceptance / sr-dev checks
- Each adapter returns valid EventObjects; numeric fields typed from structured feeds.
- Source-tier metadata present on every written row; T1 vs T2 weights applied correctly.
- Idempotency: re-running doesn't duplicate rows (keyed by published_at + url).
- No secrets/hardcoded keys in adapters — config via `.env`/registry table.

## Notes / constraints
- Read-only, no auth required for these sources where possible; document any that need a key.
- #13 uses delayed data — stamp `retrieved_at` and note delay so backtests don't treat it as real-time.
- Depends on T-001 (schema) + T-002 (dedupe/vintage layer).
