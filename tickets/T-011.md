# T-011 · Baseline strategies (Backtest Epic)

**Epic:** Backtesting & Monte Carlo · **Owner:** coder → sr-dev review · **Status:** To Do

## Goal
Implement the baseline strategies that any strategy must beat. Per @user, buy & hold on each stock/future is THE primary baseline; momentum and random-frequency are secondary baselines from §14.

## Deliverables
1. `backtest/strategies/buy_and_hold.py` — buy at start of window, hold to end. **This is the user's required baseline for every name.** Returns computed per-name so it can be compared against strategy returns on the same dates.
2. `backtest/strategies/momentum_12_1.py` — 12-1 momentum (rank by trailing 12m–1m return, hold top decile).
3. `backtest/strategies/random_frequency.py` — random rebalance at matching frequency as a sanity baseline.
4. Each strategy implements the same interface as T-010's engine; wired so results are comparable on identical dates/costs.

## Acceptance / sr-dev checks
- Buy & hold returns match an independent manual computation for a sample window (no off-by-one in holding period).
- All three strategies run end-to-end through the T-010 engine without interface mismatch.
- Momentum rebalance frequency matches §14 spec; random baseline uses matching trade frequency.

## Notes / constraints
- Depends on T-010 engine + point-in-time data provider (T-012).
- Buy & hold must be the reference line in every comparison chart/report — it's what @user explicitly asked for.
