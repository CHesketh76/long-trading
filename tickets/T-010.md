# T-010 · Backtest engine core + walk-forward harness (Backtest Epic)

**Epic:** Backtesting & Monte Carlo · **Owner:** coder → sr-dev review · **Status:** To Do

## Goal
Build the core backtest engine that simulates a strategy over price/series history using point-in-time data only. This is where signals become simulated trades and returns are computed honestly.

## Deliverables
1. `backtest/engine.py` — takes a strategy callable + a point-in-time data provider; walks forward day by day, applies the strategy's decision at each step, computes portfolio returns net of modeled transaction cost (5–15 bps/side per §14).
2. Walk-forward harness: train on t−5y…t−1y, predict t, roll yearly — **never shuffle time**. Split = 3y train / 2y test by default (configurable).
3. Point-in-time data provider interface: every price/series lookup must return only data available at decision time t. Any series that can't prove its vintage is quarantined out (§14).
4. Config-driven horizon support for the 5y total / 2y test split; results written to a structured output (JSON + optional Parquet) with per-day decisions and returns.

## Acceptance / sr-dev checks
- Walk-forward roll verified: no future data leaks into any decision step (assert by construction).
- Transaction cost applied per side; net returns reproducible.
- Output contains per-day decisions, returns, and the point-in-time guarantee holds under a fuzz test that injects out-of-vintage rows.

## Notes / constraints

- This card is the scaffold; T-012's no-cheating filter plugs in as the data-provider contract.
